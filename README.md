# Dr. Ram Physics Academy

Version 1 responsive website and PWA-ready foundation for `drkasuramachandran.com`.

## Run locally
Open `index.html` in a browser for a basic preview. For service-worker/PWA testing, use a local server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Import the repository into Vercel.
4. Deploy. No build command is required for this static version.
5. Add `drkasuramachandran.com` as a custom domain in Vercel.
6. Keep the existing research pages or move this academy into a route/subdomain after deciding the final information architecture.
